# Sample data

Everything in this directory is synthetic and supplied for local education, parser testing, and repeatable demonstration.

- `synthetic_events.json`: 1,000 normal and 100 planted security events generated by `python -m simulation.generate_logs`; every record has `simulated=true` and a `[SIMULATED]` raw-message prefix.
- `ground_truth.csv`: scenario IDs, labels, event IDs, and pipe-separated expected detection-rule IDs for each planted event.
- `metadata.json`: counts, fixed dataset end time, seed, evaluation unit, and reserved documentation IP ranges.
- `synthetic_auth.log`: six synthetic Linux SSH-auth records for parser upload demonstration. They are intentionally not part of the 1,100-event JSON evaluation dataset.
- `vulnerability_template.csv`: one clearly labelled synthetic manual risk-register import example, not vulnerability scanner output.

Do not put personal logs, secrets, or credentials in this tracked directory. Runtime databases and newly generated current datasets belong under ignored paths (`data/*.db` and `data/generated/`), not here.
